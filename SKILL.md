1. Lee AGENTS.md y README.md. Revisa el alcance aprobado y el estado de Git. Preserva cambios de terceros.
2. Define la ruta, los estados de la interfaz y el contrato mínimo de datos. Usa datos ficticios hasta que se apruebe una integración.
3. Implementa en este repositorio. Reutiliza estilos existentes del panel. Introduce una abstracción solo cuando aclare una responsabilidad o reduzca duplicación.
4. Verifica el flujo autorizado con pruebas, compilación y revisión en escritorio y móvil. Para una API futura, revisa autenticación, autorización, auditoría y validación en los límites antes de integrarla.
5. Entrega archivos cambiados, comandos reproducibles, resultados y límites de verificación.
